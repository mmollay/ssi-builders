🏗️ SiteBuilder + GlobalConfig

Komplettes Layout-Gerippe mit zentraler Konfiguration

1. GlobalConfig NEU in v1.2

Zentrale Konfiguration für alle SSI Builders. Einmal beim App-Start konfigurieren, überall nutzen!

Setup

import { GlobalConfig } from '/vendor/ssi-builders/src/index.js';

// App-Start: Einmal konfigurieren
GlobalConfig.configure({
    // Icon System
    iconPreset: 'lucide',  // 'emoji' | 'lucide' | 'heroicons' | 'material' | 'fontawesome'

    // Theme/Colors
    theme: {
        primary: '#1a73e8',
        secondary: '#5f6368',
        success: '#34a853',
        danger: '#ea4335'
    },

    // Builder Defaults
    buttons: {
        defaultSize: 'medium',
        defaultType: 'outlined'
    },

    lists: {
        itemsPerPage: 20,
        actionDisplayType: 'icon'
    },

    modals: {
        defaultSize: 'medium',
        closeOnBackdrop: true
    },

    forms: {
        submitLabel: 'Speichern',
        autoSave: false
    }
});

API Methods

Method Description Example
configure(config) Set/update configuration (deep merge) GlobalConfig.configure({ iconPreset: 'lucide' })
get(path) Get single config value GlobalConfig.get('theme.primary')
set(path, value) Set single config value GlobalConfig.set('buttons.defaultSize', 'lg')
getAll() Get complete configuration const config = GlobalConfig.getAll()
reset() Reset to defaults GlobalConfig.reset()

2. SiteBuilder NEU in v1.2

Komplettes Layout-Gerippe: Header, Sidebar, Content, Footer. Perfekt für Admin-Panels, Dashboards, und Webapps.

Quick Start

import { SiteBuilder } from '/vendor/ssi-builders/src/index.js';

const site = new SiteBuilder({
    containerId: 'app',
    layout: 'admin',  // 'admin' | 'website' | 'dashboard' | 'landing'

    header: {
        logo: '/assets/logo.svg',
        title: 'My App',
        menu: [
            { label: 'Dashboard', href: '/', icon: 'home' },
            { label: 'Users', href: '/users', icon: 'users' }
        ],
        actions: [
            { icon: 'bell', onClick: () => showNotifications() },
            { icon: 'user', onClick: () => showProfile() }
        ]
    },

    sidebar: {
        navigation: [
            { label: 'Dashboard', icon: 'home', href: '/' },
            { label: 'Users', icon: 'users', href: '/users' },
            { label: 'Settings', icon: 'settings', href: '/settings' }
        ]
    }
});

// Content rendern
site.renderContent('
Welcome!
');

// Oder: Builder direkt hinzufügen
site.addBuilder('list', {
    containerId: 'userList',
    columns: [...]
});

Layout Templates

Template Header Sidebar Footer Use Case
admin ✓ ✓ ✗ Admin Panels, Back-Office
website ✓ ✗ ✓ Marketing Websites, Blogs
dashboard ✓ ✓ ✗ Analytics, Dashboards
landing ✓ ✗ ✓ Landing Pages, Product Sites

3. SiteBuilder API

Alle verfügbaren Methoden für das SiteBuilder Layout.

Method Description Example
renderContent(html) Replace content area site.renderContent('<div>...</div>')
appendContent(html) Append to content area site.appendContent('<p>More...</p>')
clearContent() Clear content area site.clearContent()
addBuilder(type, config) Add builder to content site.addBuilder('list', {...})
toggleSidebar() Toggle sidebar collapse site.toggleSidebar()
updateHeader({...}) Update header title/logo site.updateHeader({ title: 'New' })
setActiveNavigation(href) Mark nav item as active site.setActiveNavigation('/users')
changeLayout(template) Switch layout template site.changeLayout('website')
destroy() Cleanup and remove site.destroy()

4. Real-World Beispiel

Komplette App mit GlobalConfig + SiteBuilder + ListBuilder Integration.

// === main.js - App Entry Point ===
import {
    GlobalConfig,
    SiteBuilder,
    ListBuilder
} from '/vendor/ssi-builders/src/index.js';

// 1. GlobalConfig einmalig konfigurieren
GlobalConfig.configure({
    iconPreset: 'lucide',
    theme: {
        primary: '#1a73e8',
        success: '#34a853',
        danger: '#ea4335'
    },
    lists: {
        itemsPerPage: 50,
        actionDisplayType: 'icon'
    }
});

// 2. SiteBuilder Layout erstellen
const site = new SiteBuilder({
    containerId: 'app',
    layout: 'admin',

    header: {
        title: 'HabDaWas Admin',
        logo: '/logo.svg',
        menu: [
            { label: 'Dashboard', href: '/', icon: 'home' },
            { label: 'Users', href: '/users', icon: 'users' }
        ],
        actions: [
            { icon: 'bell', onClick: () => showNotifications() }
        ]
    },

    sidebar: {
        navigation: [
            { label: 'Dashboard', icon: 'home', href: '/' },
            { label: 'Benutzer', icon: 'users', href: '/users' },
            { label: 'Spenden', icon: 'heart', href: '/donations' }
        ]
    },

    onNavigate: (href) => {
        // Router Logic
        loadPage(href);
    }
});

// 3. Content mit Buildern füllen
site.renderContent('
');

const userList = new ListBuilder({
    containerId: 'userList',
    columns: [
        { key: 'name', label: 'Name' },
        { key: 'email', label: 'E-Mail' }
    ],
    dataSource: async () => await fetchUsers(),
    actions: {
        row: [
            {
                key: 'edit',
                icon: IconManager.getIcon('edit'),  // Uses GlobalConfig preset
                label: 'Bearbeiten',
                handler: (row) => editUser(row)
            }
        ]
    }
});

5. Vorteile

Warum GlobalConfig + SiteBuilder nutzen?

  • ✅ Einmal konfigurieren - Alle Builder nutzen dieselben Einstellungen
  • ✅ Konsistentes Design - Icons, Buttons, Farben harmonisieren automatisch
  • ✅ Schnellere Entwicklung - Layout-Gerippe in 10 Zeilen Code
  • ✅ Weniger Boilerplate - Kein redundantes Header/Sidebar/Footer HTML
  • ✅ Production-Ready - Material Design 3, Responsive, Accessible
  • ✅ Flexibel - 4 Templates + Custom-Layout möglich
  • ✅ Builder-Integration - addBuilder() für nahtloses Hinzufügen
