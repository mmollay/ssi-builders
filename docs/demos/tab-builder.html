📑 TabBuilder

Accessible tabs with keyboard navigation and deep linking

📑 Underline Style (Default)

Material Design 3 primary tabs with animated underline

Code Example:

import { TabBuilder } from '/vendor/ssi-builders/src/TabBuilder.js';

const underlineTabs = new TabBuilder({
    containerId: 'underlineTabs',
    style: 'underline', // Default
    tabs: [
        {
            id: 'overview',
            label: 'Overview',
            icon: '📊',
            content: '
Overview
Dashboard overview content...
'
        },
        {
            id: 'analytics',
            label: 'Analytics',
            icon: '📈',
            content: '
Analytics
Analytics data and charts...
'
        },
        {
            id: 'settings',
            label: 'Settings',
            icon: '⚙️',
            content: '
Settings
Configuration options...
'
        }
    ],
    activeTab: 'overview',
    onChange: (tabId) => {
        console.log('Active tab:', tabId);
    }
});

underlineTabs.render();

🔗 URL Hash Support

Deep linking with URL fragments (e.g., #tab-profile)

Code Example:

const hashTabs = new TabBuilder({
    containerId: 'hashTabs',
    tabs: [
        { id: 'home', label: 'Home', content: 'Home content...' },
        { id: 'about', label: 'About', content: 'About us...' },
        { id: 'contact', label: 'Contact', content: 'Contact form...' }
    ],
    useUrlHash: true  // Enable URL hash sync
});

// Navigate to: yoursite.com/page.html#tab-about

⚙️ Configuration Options

Constructor Parameters

Parameter Type Default Description
containerId string - ID of container element (required)
tabs array [] Array of tab objects
style string 'underline' 'underline', 'pill', 'contained'
activeTab string first tab Initially active tab ID
orientation string 'horizontal' 'horizontal' or 'vertical'
useUrlHash boolean false Sync with URL hash (deep linking)
onChange function null Callback when tab changes
lazyLoad boolean false Load content only when tab activated

Tab Object Structure

{
    id: 'unique-id',           // Required: unique identifier
    label: 'Tab Label',        // Required: display text
    icon: '📊',                // Optional: icon (emoji or HTML)
    badge: '3',                // Optional: badge text
    content: '
...
',     // Required: tab panel content (HTML or function)
    disabled: false            // Optional: disable tab
}

Methods

Method Description
render() Render the tabs
setActiveTab(tabId) Switch to specific tab
getActiveTab() Get current active tab ID
addTab(tab) Add new tab dynamically
removeTab(tabId) Remove tab by ID
updateTab(tabId, updates) Update tab properties
destroy() Remove tabs and cleanup

⌨️ Keyboard Navigation

  • Arrow Left/Right - Navigate between tabs (horizontal)
  • Arrow Up/Down - Navigate between tabs (vertical)
  • Home - Jump to first tab
  • End - Jump to last tab
  • Enter/Space - Activate focused tab
  • Tab - Move focus to tab content

✨ Features

  • 3 Styles - Underline, Pill, Contained
  • Keyboard Navigation - Full ARIA support
  • URL Hash Sync - Deep linking support
  • Lazy Loading - Load content on demand
  • Icons & Badges - Visual indicators
  • Vertical/Horizontal - Flexible orientation
  • Dynamic Tabs - Add/remove tabs at runtime
  • Responsive - Mobile-friendly
