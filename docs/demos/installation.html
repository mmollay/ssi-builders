Installation

So bringst du SSI Builders in deinem Projekt zum Einsatz

1. Als Git Submodule einbinden

Die empfohlene Methode: SSI Builders als Git Submodule in dein Projekt integrieren.

  • 1

    Submodule hinzufügen

    Navigiere zum Root-Verzeichnis deines Projekts und führe folgenden Befehl aus:

    git submodule add https://github.com/mmollay/ssi-builders.git vendor/ssi-builders
  • 2

    Projekt-Struktur

    Nach dem Einbinden sollte deine Projekt-Struktur so aussehen:

    dein-projekt/
    src/
    public/
    vendor/
    ssi-builders/
    package.json
  • 3

    Updates beziehen

    Um die neueste Version von SSI Builders zu holen:

    git submodule update --remote vendor/ssi-builders

Tipp: Versioniere die Submodule-Referenz in deinem Repository, um sicherzustellen, dass alle Team-Mitglieder die gleiche Version nutzen.

2. CSS-Dateien einbinden

Binde die benötigten CSS-Dateien in deinem HTML-Dokument ein.

<!-- Design System Basis --> <link rel="stylesheet" href="/vendor/ssi-builders/src/shared.css"> <link rel="stylesheet" href="/vendor/ssi-builders/src/m3-tokens.css"> <!-- Nur die Builder importieren, die du brauchst --> <link rel="stylesheet" href="/vendor/ssi-builders/src/ListBuilder.css"> <link rel="stylesheet" href="/vendor/ssi-builders/src/FormBuilder.css"> <link rel="stylesheet" href="/vendor/ssi-builders/src/ModalBuilder.css">

Wichtig: shared.css muss immer als erstes geladen werden - sie enthält die Design Tokens für alle Komponenten.

3. JavaScript-Module importieren

Es gibt drei Möglichkeiten, SSI Builders zu importieren:

Option A: All-in-One Import (Empfohlen für die meisten Projekte)

Importiere alle Builder auf einmal - einfach und übersichtlich:

// Alles auf einmal importieren import SSI from '/vendor/ssi-builders/src/index.js'; // Verwendung: const list = new SSI.ListBuilder({ ... }); const form = new SSI.FormBuilder({ ... }); const modal = new SSI.ModalBuilder({ ... }); SSI.IconManager.setPreset('lucide');

Option B: Named Imports (Mehr Kontrolle)

Importiere nur die Builder, die du benötigst:

// Nur benötigte Builder importieren import { GlobalConfig, IconManager, ListBuilder, FormBuilder, ModalBuilder } from '/vendor/ssi-builders/src/index.js';

Option C: Dynamic Import / Lazy Loading (Beste Performance)

Lade Builder erst wenn sie gebraucht werden - optimal für große Apps:

// Lazy Loading - Builder werden erst bei Bedarf geladen async function showUserList() { const { ListBuilder } = await import('/vendor/ssi-builders/src/ListBuilder.js'); const list = new ListBuilder({ containerId: 'user-list', columns: [...], data: [...] }); list.render(); } // Modal erst laden wenn User auf Button klickt document.getElementById('open-modal-btn').addEventListener('click', async () => { const { ModalBuilder } = await import('/vendor/ssi-builders/src/ModalBuilder.js'); ModalBuilder.alert({ title: 'Hallo!', message: 'Modal wurde lazy geladen.' }); });

Performance-Tipp: Bei Vite/Webpack werden Dynamic Imports automatisch in separate Chunks aufgeteilt. So wird nur der Code geladen, der wirklich gebraucht wird!

4. GlobalConfig einrichten

Konfiguriere SSI Builders einmalig beim App-Start - alle Builder erben diese Einstellungen automatisch.

import { GlobalConfig, IconManager } from '/vendor/ssi-builders/src/index.js'; // Icon-System konfigurieren IconManager.setPreset('lucide'); // 'lucide' | 'heroicons' | 'material' | 'fontawesome' | 'emoji' IconManager.setIconWeight('regular'); // 'thin' | 'regular' | 'bold' // Globale Einstellungen GlobalConfig.configure({ iconPreset: 'lucide', iconWeight: 'regular', theme: { primary: '#1a73e8', darkMode: false }, buttons: { defaultSize: 'medium' } });

5. Deinen ersten Builder erstellen

Jetzt kannst du Builder in deinem Projekt nutzen. Hier ein einfaches Beispiel:

// HTML: <div id="user-list"></div> const userList = new ListBuilder({ containerId: 'user-list', title: 'Benutzer', columns: [ { key: 'name', label: 'Name' }, { key: 'email', label: 'E-Mail' }, { key: 'role', label: 'Rolle' } ], data: [ { id: 1, name: 'Max Mustermann', email: 'max@example.com', role: 'Admin' }, { id: 2, name: 'Anna Schmidt', email: 'anna@example.com', role: 'User' } ], options: { searchable: true, pagination: true, variant: 'elegant' } }); userList.render();

7. Dark Mode aktivieren

Aktiviere Dark Mode mit dem ThemeBuilder oder über CSS-Klassen.

// Option 1: ThemeBuilder verwenden import { ThemeBuilder } from '/vendor/ssi-builders/src/index.js'; const theme = new ThemeBuilder({ seedColor: '#1a73e8', darkMode: true, autoApply: true }); // Option 2: Manuell CSS-Klassen setzen document.documentElement.classList.add('m3-dark', 'dark-mode');

Tipp: Speichere die Dark Mode Einstellung im localStorage, um sie beim nächsten Besuch wiederherzustellen. Nutze den Theme-Button unten rechts als Referenz!
