📊 ChartBuilder

Beautiful charts with zero dependencies - Native Canvas API

📊 Bar Chart

Vertical bars with gradient colors and hover tooltips

Code Example:

import { ChartBuilder } from '/vendor/ssi-builders/src/ChartBuilder.js';

const barChart = new ChartBuilder({
    containerId: 'barChart',
    type: 'bar',
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        datasets: [{
            label: 'Sales 2024',
            data: [12, 19, 8, 15, 22, 13],
            backgroundColor: '#1a73e8'
        }]
    },
    options: {
        title: 'Monthly Sales',
        showLegend: true,
        showTooltip: true,
        responsive: true
    }
});

barChart.render();

📈 Line Chart

Smooth lines with data points and multiple datasets

Code Example:

import { ChartBuilder } from '/vendor/ssi-builders/src/ChartBuilder.js';

const lineChart = new ChartBuilder({
    containerId: 'lineChart',
    type: 'line',
    data: {
        labels: ['Week 1', 'Week 2', 'Week 3', 'Week 4'],
        datasets: [
            {
                label: 'Product A',
                data: [65, 78, 90, 81],
                borderColor: '#1a73e8',
                backgroundColor: 'rgba(26, 115, 232, 0.1)'
            },
            {
                label: 'Product B',
                data: [45, 55, 70, 65],
                borderColor: '#34a853',
                backgroundColor: 'rgba(52, 168, 83, 0.1)'
            }
        ]
    },
    options: {
        title: 'Weekly Performance',
        showLegend: true,
        smooth: true
    }
});

lineChart.render();

⚙️ Configuration Options

Constructor Parameters

Parameter Type Description
containerId string ID of the container element (required)
type string Chart type: 'bar', 'line', 'pie', 'donut'
data object Chart data with labels and datasets
options object Chart configuration options

Data Structure

data: {
    labels: ['Label 1', 'Label 2', 'Label 3'],
    datasets: [
        {
            label: 'Dataset Name',
            data: [10, 20, 30],
            backgroundColor: '#1a73e8',      // Single color or array
            borderColor: '#1a73e8',          // Line charts
            borderWidth: 2                   // Line width
        }
    ]
}

Options

Option Type Default Description
title string - Chart title
showLegend boolean true Show legend
showTooltip boolean true Show hover tooltips
responsive boolean true Auto-resize on window resize
smooth boolean false Smooth curves (line charts)
animation boolean true Animate chart rendering

Methods

Method Description
render() Render the chart
update(data) Update chart with new data
destroy() Remove chart and cleanup

✨ Features

  • Zero Dependencies - Pure Canvas API, no external libraries
  • 4 Chart Types - Bar, Line, Pie, Donut
  • Responsive - Auto-resizes on window resize
  • Interactive Tooltips - Hover to see values
  • Smooth Animations - Beautiful rendering transitions
  • Multiple Datasets - Line charts support multiple series
  • Custom Colors - Full control over colors and gradients
  • Legend Support - Optional legend display
