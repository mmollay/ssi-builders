✨ Eigene Icons hinzufügen

Fehlt ein Icon? Du kannst das System ganz einfach erweitern, indem du eigene Icons registrierst.

Custom Icon registrieren

import { IconManager } from '/vendor/ssi-builders/src/index.js';

// Neues Icon 'rocket' registrieren
IconManager.registerIcon('rocket', {
    // Für jedes Preset eine Definition hinterlegen
    lucide: '',
    emoji: '🚀',
    material: 'rocket_launch',
    fontawesome: '',
    heroicons: '' // Optional
});

// Jetzt überall nutzbar
const icon = IconManager.getIcon('rocket');
Tipp: Registriere deine Custom Icons am besten direkt beim App-Start in deiner main.js oder app.js, damit sie überall verfügbar sind.

🚀 Quick Start

1. Global konfigurieren

import { GlobalConfig } from '/vendor/ssi-builders/src/index.js';

// Einmalig beim App-Start
GlobalConfig.configure({
    iconPreset: 'lucide', // 'emoji', 'material', 'fontawesome', 'heroicons'
    iconWeight: 'regular' // 'thin', 'regular', 'bold'
});

2. In Buildern nutzen

import { ListBuilder, IconManager } from '/vendor/ssi-builders/src/index.js';

const list = new ListBuilder({
    // ...
    actions: {
        row: [
            {
                key: 'edit',
                icon: IconManager.getIcon('edit'), // Nutzt globale Config
                label: 'Bearbeiten'
            },
            {
                key: 'delete',
                icon: IconManager.getIcon('delete', 'emoji'), // Override: Immer Emoji
                label: 'Löschen',
                buttonType: 'danger'
            }
        ]
    }
});
