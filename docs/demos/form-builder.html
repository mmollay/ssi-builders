📝 FormBuilder

Dynamic forms with validation, multi-step, and auto-save

1. Basic Form Einfach

Ein einfaches Formular mit Validierung und verschiedenen Feldtypen.

import { FormBuilder } from '/vendor/ssi-builders/src/index.js'; const form = new FormBuilder({ containerId: 'basicForm', fields: [ { key: 'name', label: 'Name', type: 'text', required: true, placeholder: 'Ihr Name' }, { key: 'email', label: 'E-Mail', type: 'email', required: true, placeholder: 'ihre@email.com' }, { key: 'message', label: 'Nachricht', type: 'textarea', rows: 4, placeholder: 'Ihre Nachricht...' } ], submitLabel: 'Absenden', onSubmit: async (data) => { console.log('Form Data:', data); await new Promise(resolve => setTimeout(resolve, 1000)); alert('Formular erfolgreich gesendet!'); } });

2. Multi-Step Form NEU

Formular mit mehreren Schritten und Fortschrittsanzeige.

const multiStepForm = new FormBuilder({ containerId: 'multiStepForm', multiStep: true, steps: [ { title: 'Persönliche Daten', fields: [ { key: 'firstName', label: 'Vorname', type: 'text', required: true }, { key: 'lastName', label: 'Nachname', type: 'text', required: true } ] }, { title: 'Kontaktdaten', fields: [ { key: 'email', label: 'E-Mail', type: 'email', required: true }, { key: 'phone', label: 'Telefon', type: 'text' } ] }, { title: 'Bestätigung', fields: [ { key: 'terms', label: 'Ich akzeptiere die AGB', type: 'checkbox', required: true } ] } ], onSubmit: async (data) => { console.log('Multi-Step Data:', data); alert('Registrierung abgeschlossen!'); } });

3. All Field Types Referenz

Übersicht über alle verfügbaren Feldtypen und deren Konfiguration.

const allFieldsForm = new FormBuilder({ containerId: 'allFieldsForm', fields: [ { key: 'text', label: 'Text Input', type: 'text' }, { key: 'email', label: 'Email', type: 'email' }, { key: 'password', label: 'Password', type: 'password' }, { key: 'number', label: 'Number', type: 'number', min: 0, max: 100 }, { key: 'date', label: 'Date', type: 'date' }, { key: 'select', label: 'Select', type: 'select', options: [ { value: '1', label: 'Option 1' }, { value: '2', label: 'Option 2' } ] }, { key: 'radio', label: 'Radio Buttons', type: 'radio', layout: 'horizontal', options: [ { value: 'a', label: 'Option A' }, { value: 'b', label: 'Option B' } ] }, { key: 'checkbox', label: 'Checkbox', type: 'checkbox' }, { key: 'textarea', label: 'Textarea', type: 'textarea', rows: 3 } ], submitLabel: 'Testen', onSubmit: async (data) => console.log(data) });

Field Types Reference

Alle verfügbaren Feldtypen im FormBuilder.

Type Description Special Options
text Standard text input placeholder, minLength, maxLength
email Email input with validation placeholder
password Password input (masked) minLength, pattern
number Number input min, max, step
date Date picker min, max
select Dropdown select options: [{ value, label }]
radio Radio buttons options, layout: 'vertical' | 'horizontal' | 'grid-2' | 'grid-3'
checkbox Single checkbox -
textarea Multi-line text input rows, maxLength

Validation Options

Built-in Validierung für alle Feldtypen.

Option Type Description
required boolean Field must be filled out
minLength number Minimum text length
maxLength number Maximum text length
min number Minimum number value
max number Maximum number value
pattern RegExp Custom regex pattern
validate function Custom validation function: (value) => true | 'Error message'
// Beispiel mit Custom Validation { key: 'username', label: 'Benutzername', type: 'text', required: true, minLength: 3, validate: (value) => { if (!/^[a-zA-Z0-9_]+$/.test(value)) { return 'Nur Buchstaben, Zahlen und Unterstriche erlaubt'; } return true; } }

Advanced Features

Weitere fortgeschrittene FormBuilder Features.

Auto-Save

const form = new FormBuilder({ containerId: 'myForm', autoSave: true, // Enable auto-save to localStorage autoSaveKey: 'myForm_draft', // localStorage key autoSaveInterval: 2000, // Save every 2 seconds fields: [...] });

Conditional Fields

fields: [ { key: 'hasCompany', label: 'Firmenkunde?', type: 'checkbox' }, { key: 'companyName', label: 'Firmenname', type: 'text', showIf: (formData) => formData.hasCompany === true // Only show if checkbox is checked } ]

Custom Button Actions

const form = new FormBuilder({ containerId: 'myForm', fields: [...], submitLabel: 'Speichern', showCancelButton: true, cancelLabel: 'Abbrechen', showResetButton: true, onCancel: () => { console.log('Cancel clicked'); }, onSubmit: async (data) => { // Submit logic } });
