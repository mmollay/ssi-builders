Features

Alle Funktionen des HeaderBuilders im Überblick

🎨 Material Design 3

Google-Style Header mit MD3 Design Tokens, Elevation, und Animationen.

📑 Navigation Tabs

Horizontale Navigation mit Pill-Design, Icons, und aktiven Zuständen.

🔘 Action Buttons

Primary, Filled, und Text Buttons mit Icons und Badges.

🔍 Search Bar

Integrierte Suchleiste mit Expand-Animation und Clear-Button.

👤 User Profile

Avatar mit Dropdown-Menu für User-Aktionen.

📱 Mobile Support

Hamburger Menu mit Drawer-Navigation für Mobile Devices.

🌙 Dark Mode

Vollständige Dark Mode Unterstützung mit automatischer Anpassung.

⬆️ Elevation on Scroll

Dynamischer Schatten beim Scrollen für visuelles Feedback.

API Reference

Alle verfügbaren Konfigurationsoptionen

Constructor Options

Option Type Default Beschreibung
containerId string - Container Element ID (required)
options.logo string null Logo URL oder HTML
options.title string 'App' Anwendungstitel
options.subtitle string null Optionaler Untertitel
options.tabs Array [] Navigation Tabs: [{label, href, icon, active, badge}]
options.actions Array [] Action Buttons: [{icon, label, onClick, type, tooltip}]
options.search Object null Search Config: {placeholder, onSearch, onClear}
options.user Object null User Profile: {name, email, avatar, menu: [...] }
options.position string 'fixed' 'fixed' | 'sticky' | 'static'
options.height number 64 Header Höhe in Pixel
options.variant string 'surface' 'surface' | 'primary' | 'transparent'
options.elevateOnScroll boolean true Shadow beim Scrollen
options.showSidebarToggle boolean false Sidebar Toggle Button anzeigen
options.onSidebarToggle function null Callback für Sidebar Toggle
options.onNavigate function null Callback für Navigation: (href) => void

Methods

Method Beschreibung
render() Rendert den Header in den Container
update(options) Aktualisiert Header mit neuen Optionen
updateTitle(title, subtitle) Ändert Titel und Subtitle
setActiveTab(index) Setzt aktiven Tab
updateActionBadge(index, badge) Aktualisiert Badge eines Action Buttons
destroy() Entfernt Header und Event Listeners
