🎨 Icon Weight Demo

Thin vs. Regular vs. Bold - Modernes Stroke-Width Design

📋 Aktuell geladen: regular (Stroke-Width: 2)

🔄 Vergleich: Thin vs. Regular vs. Bold

Thin (1.5)

Eigenschaften:

  • Ultra-minimalistisch
  • Sehr feiner Strich
  • Dezent und elegant
  • Für große UI-Elemente

Regular (2.0) DEFAULT

Eigenschaften:

  • Ausgewogen & modern
  • Perfekte Lesbarkeit
  • Vielseitig einsetzbar
  • Material Design 3

Bold (2.5)

Eigenschaften:

  • Kräftig & prominent
  • Starke Betonung
  • Gut sichtbar
  • Für Akzente

💻 Code-Beispiele

Global über GlobalConfig einstellen:

import { GlobalConfig } from '/vendor/ssi-builders/src/index.js';

// Regular (DEFAULT) - Ausgewogen & modern
GlobalConfig.configure({
    iconPreset: 'lucide',
    iconWeight: 'regular'  // stroke-width: 2.0
});

// Thin - Ultra-minimalistisch
GlobalConfig.configure({
    iconPreset: 'lucide',
    iconWeight: 'thin'  // stroke-width: 1.5
});

// Bold - Kräftig & prominent
GlobalConfig.configure({
    iconPreset: 'lucide',
    iconWeight: 'bold'  // stroke-width: 2.5
});

Direkt über IconManager einstellen:

import { IconManager } from '/vendor/ssi-builders/src/index.js';

// Weight setzen
IconManager.setIconWeight('regular'); // 'thin' | 'regular' | 'bold'

// Aktuellen Weight abrufen
console.log(IconManager.getIconWeight()); // 'regular'

// Stroke-Width abrufen
console.log(IconManager.getStrokeWidth()); // 2

In Buildern nutzen:

import { ListBuilder, IconManager } from '/vendor/ssi-builders/src/index.js';

// Icons nutzen aktuellen Weight automatisch
const list = new ListBuilder({
    actions: {
        row: [
            {
                key: 'view',
                icon: IconManager.getIcon('view'), // Nutzt aktuellen Weight
                label: 'Ansehen',
                displayType: 'icon'
            },
            {
                key: 'edit',
                icon: IconManager.getIcon('edit'),
                label: 'Bearbeiten',
                displayType: 'button-icon',
                buttonType: 'primary'
            }
        ]
    }
});
