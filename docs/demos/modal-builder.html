🪟 ModalBuilder

Flexible modals with 9 sizes and layouts

1. Modal Sizes 9 Optionen

ModalBuilder unterstützt 9 verschiedene Größen und Layouts.

import { ModalBuilder } from '/vendor/ssi-builders/src/index.js'; const modal = new ModalBuilder({ size: 'medium', // xs | small | medium | large | xl | fullscreen title: 'Modal Title', content: '

Your content here...

', actions: [ { label: 'Close', type: 'secondary', onClick: (modal) => modal.close() } ] }); modal.open();

2. Side Drawers FIXED v1.2

Side-Drawer Layouts für komplexe UI-Flows (z.B. Settings, Filters).

const drawer = new ModalBuilder({ size: 'side-right', // side-left | side-right title: 'Filter Options', content: '

Filter UI here...

' }); drawer.open();

3. Bottom Sheet FIXED v1.2

Mobile-freundliches Bottom Sheet (slide-up von unten).

const sheet = new ModalBuilder({ size: 'bottom', title: 'Share Options', content: '

Share via Email, Link, etc.

' }); sheet.open();

4. Static Methods Alert, Confirm, Prompt

Schnelle Dialoge ohne Konfiguration für häufige Use-Cases.

// Alert await ModalBuilder.alert({ title: 'Success!', message: 'Your data has been saved.', type: 'success' }); // Confirm const confirmed = await ModalBuilder.confirm({ title: 'Delete Item?', message: 'This action cannot be undone.', confirmLabel: 'Delete', confirmType: 'danger' }); if (confirmed) { // Delete logic } // Prompt const name = await ModalBuilder.prompt({ title: 'Enter Your Name', message: 'Please provide your full name:', placeholder: 'John Doe' }); if (name) { console.log('Name:', name); }

5. Custom Actions

Vollständig anpassbare Action-Buttons mit M3 Design.

const modal = new ModalBuilder({ title: 'Confirm Action', content: '

Are you sure you want to proceed?

', actions: [ { label: 'Cancel', type: 'secondary', onClick: (modal) => { modal.close(); } }, { label: 'Save Draft', type: 'outlined', onClick: async (modal) => { await saveDraft(); modal.close(); } }, { label: 'Publish', type: 'primary', onClick: async (modal) => { await publish(); modal.close(); } } ] }); modal.open();

Size Reference

Alle verfügbaren Modal-Größen und -Layouts.

Size Width/Height Use Case
xs 320px Simple alerts, confirmations
small 400px Login forms, quick actions
medium 600px (Default) Standard forms, content
large 900px Complex forms, detailed content
xl 1200px Data tables, dashboards
fullscreen 100vw × 100vh Full-page experiences
side-left 400px (left edge) Navigation, filters
side-right 400px (right edge) Settings, properties panel
bottom Full width (bottom edge) Mobile actions, share sheets

Action Button Types

Alle verfügbaren Button-Typen für Modal-Actions (SSI Button System).

Type Style Use Case
primary Filled blue button Primary action (Save, Submit, Confirm)
secondary Outlined button Secondary action (Cancel, Back)
outlined Outlined button Alternative action
text Text-only button Tertiary action (Skip, Learn More)
danger Red filled button Destructive action (Delete, Remove)
success Green filled button Success action (Approve, Accept)

Advanced Options

Weitere Konfigurationsmöglichkeiten für ModalBuilder.

Option Type Description
backdrop boolean Show backdrop overlay (default: true)
closeOnBackdrop boolean Close modal when clicking backdrop (default: true)
closeOnEsc boolean Close modal on ESC key (default: true)
animation string Animation type: 'fade' | 'slide' | 'zoom' (default: 'fade')
onClose function Callback when modal closes
showCloseButton boolean Show X button in header (default: true)
const modal = new ModalBuilder({ title: 'Custom Modal', content: '

Content...

', backdrop: true, closeOnBackdrop: false, // Prevent accidental close closeOnEsc: true, animation: 'slide', showCloseButton: false, // No X button onClose: () => { console.log('Modal closed'); } });
