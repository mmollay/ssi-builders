Doc Viewer Builder

Markdown documentation viewer with XSS protection and modern styling

Features

  • ✅ Markdown Rendering - Full markdown support via marked.js
  • 🔒 XSS Protection - DOMPurify sanitization (REQUIRED)
  • 📜 Scroll-to-Top - Appears after 300px scroll
  • 🔙 Back Navigation - Optional back button
  • 🔗 Auto-Link Headings - Click-to-copy heading URLs
  • 🎨 Material Design 3 - Full M3 styling with dark mode
  • 📱 Responsive - Mobile-optimized layout
