Features

  • 5 Types - Info, Success, Warning, Error, Loading
  • 3 Variants - Soft, Outlined, Filled
  • Dismissible - Optional close button
  • Action Buttons - Add custom actions
  • Dynamic Updates - Change type/content on the fly
  • Dark Mode - Full dark theme support
  • Accessible - ARIA roles and live regions
  • M3 Design - Material Design 3 compliant

API Reference

Static Methods

Method Description
MessageBuilder.info(container, message, options) Create info message
MessageBuilder.success(container, message, options) Create success message
MessageBuilder.warning(container, message, options) Create warning message
MessageBuilder.error(container, message, options) Create error message
MessageBuilder.loading(container, message, options) Create loading message
MessageBuilder.clearAll(container) Clear all messages in container

Instance Methods

Method Description
message.dismiss() Dismiss the message with animation
message.update({ type, title, message }) Update message content dynamically
message.destroy() Remove message immediately
