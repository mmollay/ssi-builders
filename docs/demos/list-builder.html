📋 ListBuilder

Powerful data tables with search, sort, filter, and pagination. Material Design 3 compliant.

1. Basic List

Einfache Datentabelle mit Standard-Konfiguration

const list = new ListBuilder({
    containerId: 'demo1',
    columns: [
        { key: 'name', label: 'Name' },
        { key: 'email', label: 'E-Mail' },
        { key: 'status', label: 'Status' }
    ],
    dataSource: async () => [
        { id: 1, name: 'Max Mustermann', email: 'max@example.com', status: 'Aktiv' },
        { id: 2, name: 'Anna Schmidt', email: 'anna@example.com', status: 'Aktiv' }
    ]
});

2. With Icon Actions NEW

Aktions-Buttons mit verschiedenen Display-Typen

import { IconManager } from '/vendor/ssi-builders/src/index.js';

// Icon-System konfigurieren
IconManager.setPreset('lucide');

const list = new ListBuilder({
    containerId: 'demo2',
    columns: [/* ... */],
    dataSource: async () => users,
    actions: {
        row: [
            {
                key: 'view',
                icon: IconManager.getIcon('view'),
                label: 'Ansehen',
                displayType: 'icon', // Icon only (default)
                handler: (row) => alert(`View: ${row.name}`)
            },
            {
                key: 'edit',
                icon: IconManager.getIcon('edit'),
                label: 'Bearbeiten',
                displayType: 'emoji', // Emoji only
                handler: (row) => alert(`Edit: ${row.name}`)
            },
            {
                key: 'delete',
                icon: IconManager.getIcon('delete'),
                label: 'Löschen',
                displayType: 'button-icon', // Full button with icon
                buttonType: 'danger',
                handler: (row) => confirm(`Delete ${row.name}?`)
            }
        ]
    }
});

Configuration Reference

Row Actions - Display Types NEW

displayType Description Use Case
icon Icon only, compact (32x32px) - Default Space-efficient tables with many actions
emoji Emoji only, compact (32x32px) Fun, colorful UIs without dependencies
button Full button with label only Clear primary actions (Submit, Save, etc.)
button-icon Full button with icon + label Important actions that need emphasis

Button Types NEW

buttonType Style Use Case
primary Blue background, white text Primary actions (Save, Submit, Create)
secondary White background, gray text (Default) Secondary actions (Cancel, Back)
danger Red background, white text Destructive actions (Delete, Remove)
success Green background, white text Positive actions (Approve, Confirm)

Icon System NEW

Zentrales Icon-Management für konsistente UIs:

import { IconManager } from '/vendor/ssi-builders/src/index.js';

// Einmal konfigurieren (App-Start)
IconManager.setPreset('lucide'); // oder 'emoji', 'heroicons', 'material', 'fontawesome'

// Icons nutzen
icon: IconManager.getIcon('edit') // Nutzt globales Preset
icon: IconManager.getIcon('delete', 'emoji') // Override für einzelnes Icon
