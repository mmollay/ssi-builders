💬 TooltipBuilder

Accessible, positioned tooltips with Material Design 3

📍 Positionen

Tooltips können in 4 Richtungen oder automatisch positioniert werden.

🖱️ Trigger Modi

Tooltips können per Hover, Click oder manuell gesteuert werden.

🎨 Farb-Varianten

Tooltips können verschiedene Farben haben für unterschiedliche Kontexte.

📝 HTML Content

Tooltips können auch HTML-Inhalte anzeigen.

📖 API Referenz

Constructor Options

Option Type Default Beschreibung
target HTMLElement required Element, an das der Tooltip angehängt wird
content string | HTMLElement '' Tooltip-Inhalt (Text oder HTML)
position string 'top' 'top', 'bottom', 'left', 'right', 'auto'
trigger string 'hover' 'hover', 'click', 'manual'
delay number 200 Verzögerung vor dem Anzeigen (ms)
hideDelay number 0 Verzögerung vor dem Verstecken (ms)
offset number 8 Abstand zum Target-Element (px)
arrow boolean true Pfeil/Pointer anzeigen
maxWidth number 300 Maximale Breite (px)
className string '' Zusätzliche CSS-Klasse

Methoden

Methode Beschreibung
show() Tooltip anzeigen
hide() Tooltip verstecken
toggle() Tooltip umschalten (zeigen/verstecken)
setContent(content) Tooltip-Inhalt aktualisieren
destroy() Tooltip komplett entfernen & Cleanup

Events

Event Beschreibung
tooltip:show Wird ausgelöst, wenn der Tooltip angezeigt wird
tooltip:hide Wird ausgelöst, wenn der Tooltip versteckt wird
