Configuration Options

TimeRangePicker Options

Option Type Default Description
containerId string - Container element ID (required)
defaultRange string 'day' Default selected range
ranges array ['day', 'week', 'month', 'quarter', 'year'] Which range presets to show
showComparison boolean false Show comparison toggle
comparisonLabel string 'vs. Vorperiode' Label for comparison checkbox
showCustom boolean false Show custom date range option
size string 'medium' 'small', 'medium', 'large'
onChange function - Callback when range changes: (rangeData, comparisonData) => {}

Methods

Method Parameters Description
getRange() - Get current range key
getRangeData() - Get range data with start, end, label
getComparisonData() - Get comparison period data
setRange(range, trigger?) range: string, trigger?: boolean Set the active range
setCustomRange(start, end) start: Date|string, end: Date|string Set a custom date range
setComparison(enabled) enabled: boolean Enable/disable comparison
isComparisonEnabled() - Check if comparison is enabled
getSqlStartDate() - Get ISO date string for SQL queries
destroy() - Remove picker from DOM
