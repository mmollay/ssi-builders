🆕 Push Mode (v2.2.0)

Sidebar pushes content instead of overlaying it

By default, the sidebar overlays the content. With mode: 'push', the main content area shifts to make room for the sidebar, creating a more integrated layout experience.

📄 Main Content Area

This content area shifts when the sidebar expands/collapses. Click the toggle button (◂) to see the push effect!

🆕 Full Collapse Mode (v2.5.3)

Sidebar completely hides when collapsed - only a toggle button remains visible

With fullCollapse: true, the sidebar collapses to 0px width instead of the default 72px icon-only view. A floating toggle button remains visible to re-expand the sidebar.

Click the toggle button (◂) to completely hide the sidebar. A blue floating button will appear to re-expand it.
