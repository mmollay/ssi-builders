🗂️ Navigation Sidebar

Try clicking menu items, search, and toggle collapse

Code Example:

const sidebar = new SidebarBuilder({
    containerId: 'sidebarDemo',
    items: [
        {
            id: 'dashboard',
            label: 'Dashboard',
            icon: '📊',
            href: '#dashboard'
        },
        {
            id: 'products',
            label: 'Products',
            icon: '📦',
            badge: '12',
            children: [
                { id: 'all-products', label: 'All Products', href: '#products' },
                { id: 'categories', label: 'Categories', href: '#categories' },
                { id: 'add-product', label: 'Add New', href: '#add' }
            ]
        },
        {
            id: 'orders',
            label: 'Orders',
            icon: '🛒',
            badge: '5',
            href: '#orders'
        },
        {
            id: 'customers',
            label: 'Customers',
            icon: '👥',
            href: '#customers'
        },
        {
            id: 'settings',
            label: 'Settings',
            icon: '⚙️',
            children: [
                { id: 'profile', label: 'Profile', href: '#profile' },
                { id: 'security', label: 'Security', href: '#security' }
            ]
        }
    ],
    options: {
        collapsible: true,
        searchable: true,
        width: 280,
        persistent: true  // Save state to localStorage
    },
    onNavigate: (itemId) => {
        console.log('Navigated to:', itemId);
    }
});

sidebar.render();

✨ Features

  • Collapsible - Save space with collapse/expand
  • Search - Filter navigation items
  • Nested Items - Unlimited depth
  • Badges - Show counts and notifications
  • Icons - Visual navigation aids
  • Persistent State - Remembers collapse state
  • Active State - Highlights current page
  • Mobile Drawer - Responsive overlay on mobile
  • Push Mode (v2.2.0) - Content shifts instead of overlay

NEW Push Mode (v2.2.0)

Sidebar pushes content instead of overlaying it

By default, the sidebar overlays the content. With mode: 'push', the main content area shifts to make room for the sidebar, creating a more integrated layout experience.

Push Mode Example:

import { SidebarBuilder } from '/vendor/ssi-builders/src/SidebarBuilder.js';

const sidebar = new SidebarBuilder({
    containerId: 'sidebar-container',
    items: navigationItems,
    options: {
        mode: 'push',                    // NEW: Content is pushed
        mainContentSelector: '#main',    // CSS selector for content
        collapsible: true,
        width: 280,
        collapsedWidth: 72
    }
});

sidebar.render();

// Dynamic mode switching
sidebar.setMode('overlay');  // Switch to overlay
sidebar.setMode('push');     // Switch back to push
sidebar.getMode();           // Returns 'push' or 'overlay'

Mode Comparison:

Feature Overlay (default) Push
Content behavior Stays in place, sidebar overlays Shifts with sidebar width
Best for Mobile, temporary navigation Desktop, persistent layouts
Mobile behavior Overlay Falls back to overlay
Animation Sidebar slides in Sidebar + content animate

Configuration Options

{
    containerId: 'sidebar',           // Container element ID
    items: [...],                     // Navigation items (required)
    options: {
        collapsible: true,            // Allow collapse/expand
        searchable: true,             // Show search box
        width: 280,                   // Sidebar width (px)
        collapsedWidth: 72,           // Width when collapsed (px)
        persistent: true,             // Save state to localStorage
        defaultCollapsed: false,      // Start collapsed
        position: 'left',             // 'left' or 'right'
        mode: 'overlay',              // NEW v2.2.0: 'overlay' or 'push'
        mainContentSelector: null     // NEW v2.2.0: CSS selector for push mode
    },
    onNavigate: (itemId) => {...},   // Navigation callback
    onToggle: (collapsed) => {...}   // Collapse state callback
}
