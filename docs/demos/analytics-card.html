AnalyticsCard

KPI Cards for Analytics Dashboards with trend indicators, multiple formats, and loading states

1. Basic KPI Cards NEW

Simple KPI cards with different value formats

2. Cards with Trend Indicators

Show performance changes with up/down/neutral trends

3. Color Variants

Different accent colors for visual categorization

4. Size Variants

Small, medium (default), and large card sizes

5. Loading State

Skeleton loading animation while data is being fetched

6. Clickable Cards (Drill-Down)

Cards that navigate or trigger actions on click

7. AnalyticsCardGrid NEW

Helper class to create multiple cards in a responsive grid

Configuration Options

AnalyticsCard Options

Option Type Default Description
containerId string - Container element ID (required)
label string - KPI label/title
value number|string - KPI value
format string 'number' 'number', 'currency', 'percent', 'time', 'compact'
currencySymbol string '$' Currency symbol for currency format
decimals number 0 (2 for currency) Decimal places
icon string - Icon name from IconManager
subtext string - Secondary text below value
trend object - { direction: 'up'|'down'|'neutral', value: number, label?: string }
color string 'primary' 'primary', 'success', 'warning', 'error', 'purple'
size string 'medium' 'small', 'medium', 'large'
loading boolean false Show loading skeleton
onClick function - Click handler for drill-down
href string - Link URL (renders as anchor tag)

Methods

Method Parameters Description
update(value, trend?) value: number|string, trend?: object Update the card value and optionally trend
setLoading(loading) loading: boolean Set loading state
destroy() - Remove the card from DOM
