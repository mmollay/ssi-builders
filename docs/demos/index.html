🚀 Getting Started

SSI Builders ist eine professionelle UI-Komponenten-Bibliothek basierend auf Material Design 3. Jede Seite in dieser Dokumentation zeigt dir:

  • ✅ Live-Beispiele zum Ausprobieren
  • ✅ Code-Snippets zum Kopieren
  • ✅ Alle Konfigurations-Optionen dokumentiert
  • ✅ Best Practices und Tipps
  • ✅ Icon-System Integration

Schnell-Installation

Als Git Submodule in dein Projekt einbinden:

git submodule add https://github.com/mmollay/ssi-builders.git vendor/ssi-builders

Erstes Beispiel

<!-- HTML -->
<div id="myList"></div>

<!-- JavaScript -->
<script type="module">
import { ListBuilder, IconManager } from '/vendor/ssi-builders/src/index.js';

// Icon-System konfigurieren
IconManager.setPreset('lucide');

// ListBuilder erstellen
const list = new ListBuilder({
    containerId: 'myList',
    columns: [
        { key: 'name', label: 'Name' }
    ],
    dataSource: async () => [
        { id: 1, name: 'Item 1' }
    ]
});
</script>

🎨 Icon-System

SSI Builders verfügt über ein zentrales Icon-Management-System. Einmal konfigurieren, überall nutzen!

  • emoji - Native Emojis (keine Dependencies)
  • lucide - Lucide Icons (empfohlen für M3)
  • heroicons - Heroicons (Tailwind CSS)
  • material - Material Icons (Google)
  • fontawesome - FontAwesome Icons
