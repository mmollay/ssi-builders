🤖 MCP Server für Claude Code

AI-optimierte Integration: Reduziere Token-Kosten um 70% und beschleunige die Entwicklung mit SSI Builders

Was ist der MCP Server? NEU v1.0.0

Der Model Context Protocol (MCP) Server stellt Claude Code strukturierte Informationen über SSI Builders zur Verfügung - ohne jedes Mal die gesamte Dokumentation durchsuchen zu müssen.

⚡ Instant Zugriff

Claude Code erhält sofort präzise Infos zu jedem Builder - keine Datei-Suche, kein Context-Bloat.

💰 70% Token-Ersparnis

Strukturierte Daten statt Full-Text-Suche. Haiku statt Sonnet für einfache Tasks.

📝 Code-Generierung

Ready-to-use Snippets für alle Komponenten. Copy-Paste, fertig!

🔍 Intelligente Suche

Suche nach Features ("dark mode"), Use Cases ("CRUD"), Keywords ("validation").

🛠️ Verfügbare Tools

1. ssi_list_components

Liste aller verfügbaren SSI Builder Komponenten mit optionalem Kategorie-Filter.

2. ssi_get_component_info

Detaillierte Dokumentation für eine spezifische Komponente.

3. ssi_generate_code

Generiere ready-to-use Code-Snippets.

4. ssi_search_components

Suche Komponenten nach Keyword, Feature, oder Use Case.

5. ssi_check_updates

Prüfe auf neue SSI Builders Versionen und update automatisch.
