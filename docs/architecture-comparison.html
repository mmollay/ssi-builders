🎯 Why This Architecture is Professional

1. Separation of Concerns

SSI Builders: Reine UI Library ohne Business Logic

Habbi Search: Business Logic + Data Management

✓ Wie Google MDC + Google Analytics trennt

2. Single Source of Truth

GlobalConfig einmal konfigurieren beim App-Start

Alle Builders erben automatisch die gleichen Settings

✓ Wie React Context Provider

3. Git Submodule Pattern

Zentrale Updates: SSI Builders updaten → alle Projekte profitieren

Version Control: Jedes Projekt wählt seine SSI Builders Version

✓ Wie Google's Monorepo Strategy

4. Design Token System

CSS Custom Properties: --ssi-primary, --ssi-spacing-md

Runtime Änderungen: Theme-Switching ohne Rebuild

✓ Wie Material Design 3 Tokens

5. DRY Principle

BaseBuilder: Gemeinsame Funktionalität (init, render, destroy)

Specialized Builders: Nur spezifische Features implementieren

✓ Wie React Component Inheritance

6. Scalability

Neue Builder: Einfach neue Klasse von BaseBuilder ableiten

Neue Projekte: Git Submodule hinzufügen + GlobalConfig = fertig

✓ Wie Facebook's Component Library

🔍 Real Integration Flow in Habbi Search

Step 1: HTML Setup (index.html)
<!DOCTYPE html>
<html lang="de">
<head>
<!-- SSI Builders Design Tokens -->
<link rel="stylesheet" href="/vendor/ssi-builders/src/shared.css">
<link rel="stylesheet" href="/vendor/ssi-builders/src/ListBuilder.css">
<link rel="stylesheet" href="/vendor/ssi-builders/src/ModalBuilder.css">
</head>

Step 2: GlobalConfig (main.js - ONCE per App!)
import { GlobalConfig, IconManager } from '/vendor/ssi-builders/src/index.js';

// Configure ONCE at app startup
GlobalConfig.configure({
iconPreset: 'lucide', // Icon system for ALL builders
iconWeight: 'regular', // Icon weight for ALL builders
theme: {
primary: '#1a73e8', // Brand color
success: '#34a853'
},
lists: {
itemsPerPage: 20, // Default for ALL ListBuilders
actionDisplayType: 'icon'
}
});

Step 3: Use Builders (category-admin-new.html)
import { ListBuilder } from '/vendor/ssi-builders/src/ListBuilder.js';
import { ModalBuilder } from '/vendor/ssi-builders/src/ModalBuilder.js';

// ListBuilder automatically uses GlobalConfig settings!
const list = new ListBuilder({
containerId: 'categories-list',
columns: [
{ key: 'id', label: 'ID' },
{ key: 'name', label: 'Category' }
],
dataSource: async () => {
const { data } = await supabase.from('categories').select('*');
return data;
},
actions: {
edit: {
icon: IconManager.getIcon('edit'), // Uses GlobalConfig icon preset!
onClick: async (item) => {
// ModalBuilder also uses GlobalConfig!
const modal = new ModalBuilder({
title: 'Edit Category',
// size/animation/etc from GlobalConfig.modals
});
}
}
}
// pageSize, actionDisplayType, etc. from GlobalConfig.lists!
});

list.render();
